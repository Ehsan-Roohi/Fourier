# R13–R26 rarefied-cavity JFM package

This repository is the public reproducibility record for the revised JFM
manuscript **“What does anti-Fourier heat-flux agreement validate? DSMC
sensitivity and R13–R26 diagnostics in a rarefied cavity.”**

The maintained submission package is
[`r13-r26-cavity/`](r13-r26-cavity/).  Its own
[`README.md`](r13-r26-cavity/README.md) describes the manuscript, numerical
evidence, exact reproduction commands, and file manifest.  Implementation
lineage and state hashes are recorded in
[`CODE_PROVENANCE.md`](r13-r26-cavity/CODE_PROVENANCE.md).

The `Fourier*.ipynb` and `Untitled38.ipynb` files at the repository root are
older notebook records and are not the entry point for reproducing the JFM
results.

## Protected article code

All content under `r13-r26-cavity/` is protected scientific material.  General
repository cleanup must not reformat, rename, move, squash, delete, or combine
its R13/R26/DSMC code, data, hashes, numerical constants, or status labels.
Read [`JFM_R13_R26_PROTECTION.md`](JFM_R13_R26_PROTECTION.md) before proposing
a scientific change.

## Scope

The repository is a commit-addressed public record, not an archival DOI.  Use
the exact commit and the file-level hashes supplied by the package when citing
or reproducing a result.  A repository-wide license has not been declared;
source and data reuse terms must be confirmed before redistribution.
